# Code of conduct

Jellybeam is a small project run for the people who use it. Everyone taking
part in its issues, discussions, and pull requests is expected to keep it a
welcoming place, whatever their experience, background, or identity.

## Expected

- Be kind and assume good faith. Most bug reports come from someone who is
  already frustrated with their TV.
- Critique code and ideas, not people.
- Accept a "no" on scope gracefully; not every good idea fits the app.
- Keep other people's details private. Never post someone's server address,
  account, library contents, or personal information.

## Not acceptable

- Harassment, insults, or personal attacks, in public or in private.
- Sexualised language or imagery, or unwelcome attention of any kind.
- Discriminatory jokes or language.
- Publishing anyone's private information without their explicit permission.
- Repeatedly derailing threads or ignoring a maintainer's request to stop.

## Enforcement

Report a problem with GitHub's **Report content** option on the comment,
issue, or pull request in question. Maintainers will review every report and
may edit or remove content, lock threads, or block people from the project,
temporarily or permanently, as the situation warrants. Reporters' identities
are kept private.

This code applies in every project space on GitHub and wherever someone is
representing the project elsewhere.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
